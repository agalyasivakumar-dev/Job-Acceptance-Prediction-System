# Job Acceptance Prediction System

## Project Overview
The Job Acceptance Prediction System is a machine learning project that analyzes candidate information to predict placement status. It uses academic performance, technical skills, communication skills, work experience, and job-related factors to understand placement outcomes.

## Objectives
- Analyze candidate performance and placement trends.
- Clean and prepare the dataset for analysis.
- Identify factors associated with placement outcomes.
- Build a machine learning classification model to predict placement status.
- Present insights through a Streamlit dashboard.

## Dataset
- **Total records:** 51,500
- **Total columns:** 26
- **Target column:** `status`
- **Target values:** `Placed` and `Not Placed`

The dataset contains academic scores, interview-related scores, experience, job preferences, company tier, and other candidate-related information.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib, Seaborn and Plotly
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Project Workflow
1. Load and understand the dataset.
2. Clean missing values, duplicates, and inconsistent data.
3. Perform exploratory data analysis (EDA).
4. Identify important factors related to placement.
5. Train and evaluate machine learning classification models.
6. Develop an interactive Streamlit dashboard.

## Expected Outcome
The system aims to identify patterns in candidate placement outcomes and provide predictions based on the trained machine learning model.

## Conclusion
This project combines data analysis, SQL, machine learning, and dashboard development to support data-driven placement analysis.
